# TORIYA NOVA — Business Architecture Lab MVP

Боевой MVP Telegram Mini App под набор практической группы со стартом 5 сентября.

## Что уже работает

- 12 вопросов без «психотипов»: контекст бизнеса, клиент/JTBD, конкуренты, путь клиента, архитектура/MVP, AI-контекст.
- 6 индексов зрелости и общий индекс ясности.
- Персонально определяется самое слабое звено и 3 следующих действия.
- Отдельно показывается, что именно AI сейчас вынужден додумывать за бизнес.
- Финальный оффер группы: 10 человек, старт 5 сентября, 7 000 ₽.
- Кнопка «Оставить заявку на место» отправляет Тории Telegram-контакт человека + общий индекс + слабое звено.
- Простая аналитика в `analytics.jsonl`: вход, старт, прогресс, результат, CTA, заявка.
- Результат хранится внутри браузера Mini App (`localStorage`), PDF/скачивания нет.
- При каждом входе сервер валидирует Telegram `initData` и проверяет членство в канале через `getChatMember`.
- Если пользователь отписался, содержимое блокируется; при повторной подписке локальный результат снова открывается.
- В обычном интернете приложение не открывает диагностику без Telegram. Локально на компьютере работает DEMO-режим для проверки.

## Уже выставлено в MVP

- Канал: `https://t.me/tori_ya_nova`
- Старт: 5 сентября
- Мест: 10
- Цена: 7 000 ₽

## Настройка сервера

Скопируйте `.env.example` в `.env` и заполните:

```bash
BOT_TOKEN=123456:ABC...
CHANNEL_ID=@tori_ya_nova
OWNER_CHAT_ID=123456789
PORT=3000
```

`OWNER_CHAT_ID` — личный числовой Telegram ID Тории. Его можно узнать через любого сервисного бота, показывающего ваш Telegram user id. Сначала откройте/запустите собственного бота, чтобы он мог присылать вам сообщения.

Бота лучше добавить администратором канала `@tori_ya_nova`, чтобы проверка подписки через `getChatMember` работала стабильно.

Запуск:

```bash
npm start
```

Нужен публичный HTTPS-адрес. Его URL указывается в BotFather как URL Telegram Mini App / Web App кнопки.

## Локальная проверка

```bash
npm start
```

Открыть `http://localhost:3000` — на localhost включится DEMO. Можно пройти весь сценарий без Telegram; отправка заявки имитируется и никуда не уходит.

## Проверить перед публикацией

1. Создать/выбрать Telegram-бота.
2. Добавить его администратором `@tori_ya_nova`.
3. Заполнить `BOT_TOKEN`, `CHANNEL_ID`, `OWNER_CHAT_ID`.
4. Разместить папку на HTTPS-хостинге с Node.js.
5. В BotFather привязать HTTPS URL как Mini App/Web App.
6. Проверить: подписан → доступ; не подписан → lock; отписался → lock; CTA → заявка приходит Тории.
7. После первых заходов смотреть `analytics.jsonl`: сколько дошли до старта, результата и заявки.

## Логика продукта

Не «продаём обучение архитектуре». Сначала пользователь сам обнаруживает незаданные части своего бизнеса. Затем приложение показывает, что без них нейросеть будет заполнять неизвестное шаблонами. Только после этого появляется группа как способ пройти весь цикл на своём проекте: исследование → путь → архитектура → контекст для AI → MVP.
